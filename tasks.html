Задачи для экзамена

1. Управление предприятием (производством).

1.1. Подготовка каталога продукции гипермаркета со стандартизированной структурой по методологии БЭМ. Задача: подготовить структуру каталога гипермаркета с векторными изображениями по методологии БЭМ. ПримерСопутствующие материалы

1.2. Подготовка схемы аэропорта с учетом правил пассажироперевозок. Задача: показать все функциональные возможности аэропорта по заданным визуальным приоритетам в заданной цветовой схеме и формате А3. ПримерСопутствующие материалы

1.3. Подготовка рекламного модуля для представления нового смартфона с учетом актуальных технологий. Задача: подготовить рекламный модуль для представления смартфона с указанием преимуществ из технического описания и графических атрибутов из библиотеки SVG файлов. ПримерСопутствующие материалы

2. Веб-дизайн (графические и логические рекламные навыки).

2.1. Верстка целевой рекламной страницы и анимация SVG графики на основе шаблона HTML5. Задача: показать преимущества новой услуги (на выбор - розничное кредитование, туризм, спортивный клуб), показать навыки веб-дизайнера. ПримерСопутствующие материалы

2.2. Дизайн уникального логотипа для компании на выбор из примеров в соответствии со всеми требованиями к разработке логотипа. Задача: выявить навыки дизайнера логотипов (брендинг). ПримерСопутствующие материалы

2.3. Дизайн титульного изображения для приложения с целью размещения на рабочем столе смартфона iOS, Android. Задача: подготовить уникальное изображение по заданной тематике под формат iOS, Android по стандартным модульным сеткам и цветовым палитрам. Проверка на уникальность, соответствие модульной сетке и формату экспорта в приложение. ПримерСопутствующие материалы

3. Картография (навигация в сложной логистике).

3.1. Дизайн схемы проезда от офиса компании к складу с наименьшими потерями по времени на автомобиле, метро, автобусе. Задача: выявить практические навыки к картографии и логистике. ПримерСопутствующие материалы

3.2. Дизайн оригинальной схемы размещения отделов гипермаркета в соответствии с фирменным стилем компании (для продажи товаров со скидками). Задача: показать навыки рекламного дизайна и картографии. ПримерСопутствующие материалы

3.3. Дизайн фрагмента схемы метро с учетом требований к навигации. Задача: показать навыки картографии и применения SVG графики. ПримерСопутствующие материалы
