# Online Course Platform

Portfolio version of a web-based online learning platform originally developed in 2020–2021.

The project demonstrates a custom PHP/JavaScript educational website with course navigation, lectures, practical assignments, examinations, student progress/results, file-upload UI, feedback/payment forms, FAQ, learning materials and a personal-area interface.

## Stack

- PHP
- JavaScript / jQuery
- HTML5
- CSS3
- CSV-based data processing
- SVG

## Main modules

- Course landing and information pages
- Lectures and video lectures
- Practical assignments and examination flow
- Student results and detailed progress views
- File-upload interface for examination work
- Login/password-reset interface prototypes
- Feedback and enrollment/payment forms
- FAQ, literature, calendar and additional materials

## Repository structure

- `css/` — interface styles
- `js/` — client-side interactions, galleries and sliders
- `img/` — interface and educational media
- `data/` — demonstration CSV data and CSV parser
- root PHP/HTML files — course pages and application screens

## Portfolio note

This repository is a sanitized portfolio snapshot of a historical project. Personal student records and private contact details have been removed or replaced with demonstration values. Some server-side endpoints referenced by the UI belonged to the original deployment and are not included in this public repository, so the repository should be treated primarily as a source-code and interface showcase rather than a turnkey production deployment.

## Data privacy

The public version contains synthetic demonstration records only. Do not commit real student data, credentials, private email addresses or production configuration.
